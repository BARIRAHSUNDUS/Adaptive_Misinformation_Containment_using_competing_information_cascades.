# Module 1 - Social Graph

## Responsibility

This module represents the social network as a graph.

## Main Components

- User class
- SocialGraph class
- Adjacency list representation
- User connections
- Degree calculation
- Neighbour lookup
- BFS traversal

## Data Structures

- Graph
- Adjacency List
- Vector
- Queue

## Classes

### User
Represents an individual user using a unique user ID.

### SocialGraph
Represents the social network and manages users and their connections.
